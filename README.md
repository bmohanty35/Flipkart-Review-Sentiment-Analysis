🚀 Project Completed: Sentiment Analysis of Real-Time Flipkart Product Reviews

I’m excited to share my recent end-to-end Machine Learning project on Sentiment Analysis of Flipkart Product Reviews, completed during my ongoing internship at Innomatics Research Labs.

🔍 What this project does:
Classifies customer reviews into Positive and Negative sentiments
Identifies customer pain points from negative reviews
Demonstrates a complete ML lifecycle from data preprocessing to deployment

🛠 Tech Stack & Approach:
NLP preprocessing: text cleaning & lemmatization
Feature extraction: BoW, TF-IDF, Word2Vec, and BERT
Model comparison: Logistic Regression, Naive Bayes, Random Forest, LinearSVC, and LSTM
Best model: LinearSVC (highest F1-score)
Deployment: Streamlit app deployed on AWS EC2

📈 Key Learning:
 LinearSVC proves to be highly effective for high-dimensional text data, offering strong performance with faster training and easier deployment compared to deep learning models.
